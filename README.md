# 🐾 PetViva - Landing Page 

## 👩‍💻 Autor(a)
Ana Flávia de Freitas Corrêa  

## 📌 Identificação do Projeto
Este projeto consiste no desenvolvimento de uma **landing page responsiva** para um pet shop fictício chamado **PetViva**, com foco em um visual moderno, sofisticado e funcional.

A aplicação foi construída utilizando tecnologias fundamentais do desenvolvimento front-end:
- HTML5 (estrutura semântica)
- CSS3 (estilização e responsividade)
- JavaScript (interatividade e manipulação do DOM)

---

## 🎯 Objetivo
Criar uma página web que simule um site profissional de pet shop, aplicando conceitos de:
- Estruturação semântica
- Design responsivo
- Experiência do usuário (UX)
- Interatividade com JavaScript

---

## 🛠️ Etapas de Desenvolvimento

### 1. Planejamento e Identidade Visual
- Definição do nome **PetViva**
- Escolha de um estilo visual premium
- Definição da paleta de cores:
  - Roxo (principal)
  - Dourado (destaque)
  - Branco e cinza (base)
- Escolha das fontes:
  - Montserrat (títulos)
  - Roboto (textos)

---

### 2. Estruturação com HTML
- Uso de tags semânticas:
  - `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- Organização das seções:
  - Hero (destaque)
  - Sobre
  - Serviços
  - Contato

---

### 3. Estilização com CSS
- Uso de:
  - Flexbox (layout)
  - Grid (organização de conteúdo)
  - Variáveis CSS
- Criação de:
  - Cards com `aspect-ratio`
  - Layout responsivo (mobile e desktop)
- Aplicação de efeitos visuais:
  - Hover
  - Sombras
  - Bordas arredondadas

---

### 4. Interatividade com JavaScript
- Implementação de:
  - Menu mobile (hamburguer)
  - Scroll suave entre seções
  - Validação de formulário:
    - Nome obrigatório
    - Email válido
    - Mensagem obrigatória
- Feedback visual ao usuário

---

## 💻 Como Executar o Projeto

### ✔️ Método 1 — Simples (Recomendado)
1. Baixe ou clone o projeto
2. Abra a pasta no computador
3. Clique duas vezes no arquivo: index.html


---

### ✔️ Método 2 — Usando VS Code
1. Abra o projeto no VS Code
2. Instale a extensão **Live Server**
3. Clique com botão direito no `index.html`
4. Clique em: Open with Live Server
